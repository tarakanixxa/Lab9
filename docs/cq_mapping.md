# CQ mapping — Lab 9

Предметна область: управління виробничим комплексом «Львів» / завод «Метал-Деталь».
Дані навчальні та синтетичні; вони не описують реальні показники підприємства.

| CQ | Компетентнісне питання | Шаблон Cypher-шляху |
|---|---|---|
| CQ01 | Які цехи належать заводу? | `(f:Factory)-[:HAS_WORKSHOP]->(w:Workshop)` |
| CQ02 | Які верстати розташовані в кожному цеху? | `(w:Workshop)-[:CONTAINS_MACHINE]->(m:Machine)` |
| CQ03 | Хто керує верстатами та до якого цеху закріплений? | `(e:Employee)-[:OPERATES]->(m:Machine); (e)-[:ASSIGNED_TO]->(w)` |
| CQ04 | Який матеріал і в якій кількості є на складі? | `(i:Inventory)-[:STORES_MATERIAL]->(m:Material)` |
| CQ05 | Які дефекти зафіксовані у продукції? | `(p:Product)-[:HAS_DEFECT]->(d:Defect)` |
| CQ06 | Яка послідовність технологічних операцій? | `(o:Operation)-[:NEXT_OPERATION*1..5]->(o2:Operation)` |
| CQ07 | Який найкоротший шлях між верстатом і продуктом? | `shortestPath((m:Machine)-[*..6]-(p:Product))` |
| CQ08 | Скільки дефектів пов'язано з кожним верстатом? | `(m:Machine)<-[:DETECTED_ON]-(d:Defect)` |
| CQ09 | Які сутності залежать від верстата до глибини 3? | `(m:Machine)-[*1..3]-(x)` |
| CQ10 | На які процеси/продукти може впливати дефект? | `(d:Defect)-[*1..3]-(x)` |
| CQ11 | Які верстати мають заплановане або виконане ТО? | `(m:Machine)-[:HAS_MAINTENANCE]->(t:Maintenance)` |
| CQ12 | Які продукти пов'язані з матеріалами через процес? | `(m:Material)-[:REQUIRED_FOR]->(p:Product)-[:RESULT_OF]->(pr:Process)` |

## Походження знань
Кожне ребро містить `source`, `confidence`, `validFrom`. `source` — назва джерела/набору даних; `confidence` — умовна оцінка впевненості; `validFrom` — дата початку чинності факту. У цьому навчальному наборі ці значення синтетичні.

## Порівняння з онтологією ЛР 7

| OWL-клас / поняття ЛР 7 | LPG-представлення ЛР 9 | Рішення |
|---|---|---|
| ВиробничийКомплекс | `:ProductionComplex` | Клас став окремою міткою |
| Завод | `:Factory` | Клас став окремою міткою; `(:ProductionComplex)-[:HAS_FACTORY]->(:Factory)` |
| Цех | `:Workshop` | Клас став міткою |
| Обладнання | `:Machine` | Клас став міткою |
| Персонал | `:Employee` | Клас став міткою |
| Матеріали та сировина | `:Material` | Клас став міткою |
| Виробничий процес | `:Process` | Клас став міткою |
| Технологічна операція | `:Operation` | Клас став міткою |
| Продукція | `:Product` | Клас став міткою |
| Дефект | `:Defect` | Клас став міткою |
| `назва`, `статус`, `потужністьКВт`, `кількістьНаСкладі` | `name`, `status`, `powerKw`, `quantity` | Datatype properties стали властивостями вузлів |
| `маєЦех`, `використовуєОбладнання`, `ґрунтуєтьсяНаДефекті` | `HAS_WORKSHOP`, `CONTAINS_MACHINE`, `HAS_DEFECT` тощо | Object properties стали типами зв'язків |

Примітка: LPG-схема є цільовою проєкцією для CQ, а не механічною копією OWL. Частина онтологічних понять може бути агрегована або деталізована залежно від запитів.
